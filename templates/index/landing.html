How the index is built

No surveys, no self-reported data - every number comes from the same pages regulated operators show their own players, read the same way every night.

1

Sniff the lobby

Each operator's homepage and live-casino section is crawled nightly, reading the same lobby data their own site loads for a real player.

2

Score by placement

A hero banner slot counts for more than page 3 of a grid - every tile is weighted by section and on-page position before anything is compared.

3

Rank the market

Scores roll up per title, per provider, and per regulated market, so you can see what's actually being pushed to players this week.
